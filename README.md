# 判断力训练机（Judgment Engine）

目标：培养 AI 时代无法外包的判断力——**验真 / 修错 / 评判**。
第一性原理：判断力 = 脑内内部模型与现实之间的吻合度。训练 = 反复制造"预测 vs 现实"的碰撞并修复内部模型。

## 核心循环（每次学习 = 跑一遍循环）
选一个"物体" → 建立内部模型（从零实现 / 闭卷推导 / 讲清楚）→ 预测（改变 X 会怎样？）→ 现实验证 → 记录偏差 → 修复内部模型

## 目录
- `ledgers/`      预测账本（进步的账本，每轮一份）
- `toolkit/`      验证工具箱（"现实"的代言人，已测试）
- `dictionaries/` 故障字典（症状 → 根因 → 定位方法）
- `protocols/`    AI 陪练协议与记录
- `checklists/`   每周自评清单
- `objects/`      循环物体（按负重级递增：①形状 ②动态 ③组件 ④系统 ⑤研究）

## 升级规则
连续两轮循环预测命中率 ≥ 80% 且闭卷重写数值误差 < 1e-5 → 升一级负重。

## 铁律
AI 输出永远是"待验证的命题"，不是终点。你负责验真、修错、评判。

## 素材仓库
.Prime / 周期课程 / 论文 —— 全部是"取料的仓库"，不是路线图。顺序由判断力缺口决定。
