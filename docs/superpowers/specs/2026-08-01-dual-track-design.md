## 一、设计动机(来自头脑风暴)

原系统把"从零实现 / 闭卷重写 / 数值误差 <1e-5"作为理解判据。经澄清:

- **手写代码本身无意义**——人类写代码赢不过 AI,不为表演而敲码
- **理解 ≠ 背诵**:死记原理 = 机器学习里的过拟合。见过的问题答得再好不算数
- **理解 = 能讲清 + 能迁移**:能经得住内行追问的机制解释(B)+ 能在新场景预测对(C)
- **不闭卷从头推导**——那是数学家物理学家的事;目标是**用对工具、泛化、迁移**
- **训练集 / 测试集必须分离**:原系统的预测命中率统计的是"训练集"表现,会过拟合

## 二、核心改动:单一循环 → 双轨

```
┌─────────────────────────────┐
│  学习轨(不记分,练理解)         │
│  认领物体 → 写解释稿            │
│  → AI 内行追问(答不上→回去补)   │
│  产出: explanations/ 解释稿    │
└─────────────────────────────┘
            ↓ 原理装进脑内模型
┌─────────────────────────────┐
│  判断轨(记分,测泛化)           │
│  给陌生代码/场景 → 限时预测      │
│  → toolkit/实验验证 → 记偏差    │
│  产出: ledgers/ 预测记录        │
└─────────────────────────────┘
```

- 学习轨 = 训练集(练理解,不记分)
- 判断轨 = 测试集(测泛化,记分,只用新场景)

## 三、学习轨(不记分)

1. **认领物体**:从 `objects/` 或素材源选一个原理单点(不要求完整代码,如"softmax 的数值稳定性")
2. **写解释稿**:先自己写,允许翻资料,**禁止直接抄 AI 讲解**,再与 AI 对照
3. **AI 内行追问**:连续 3-5 轮追问,答不上来的地方 = 内部模型缺口,当场记录
4. **产出**:解释稿存 `explanations/`,缺口记入故障字典的"理解缺口"分类

**解释稿格式要求(强制):**
- 3 句话以内讲清"这个机制解决什么问题 + 怎么解决"
- 300-500 字展开:关键推导/关键代码行 + 1-2 个自创例子
- 必须包含一句"如果我没有 X,会怎样?"(强制写出依赖条件 = 泛化边界)
- 禁止粘贴 AI 原文

**质量门槛**:解释稿必须通过 AI 追问才算完成。连续 2 次被追问卡住同一原理 → 判定未消化,退回重学,且禁止升级。

**频率**:每周 2 个学习轨物体。

## 四、判断轨(记分)

1. **取题**:从素材源拿一个陌生代码文件(没读过才能当题,读完再预测就废了)
2. **预测关(限时 15-20 分钟)**:写下 3-5 条量化预测,每条含通过判据
   - 输入形状 → 输出形状(`matmul_result_shape`)
   - 边界输入行为(`boundary_attack`)
   - 具体数值(`gradient_check` / numpy 实测)
3. **验证关**:toolkit + numpy 实测,逐条判对错
4. **记偏差**:预测错的条目,根因进故障字典
5. **记分**:命中数 / 总数,只统计"新场景"

**题型混合(先易后难,不让人受挫):**
- 初期以 B(读码后扰动)为主:读完代码,预测"改 X 会怎样"
- 熟练后混入 A(盲猜):只看签名/注释预测行为
- A 的比例随负重级提升而增加

**防过拟合硬规则:**
- 一个代码文件只能被预测一次,第二次见不算分
- AI 生成变体必须"换场景不换原理"(如学过 softmax → 出 attention 里的 softmax + 温度缩放)

**频率**:每周 2-3 个判断轨物体(1 个 GitHub + 1-2 个 AI 变体)。

## 五、素材源

三个来源:

1. **GitHub(主力)**:按方向(机器学习 / 图像处理 / 因果推断)收集仓库;每周取 1 个函数/文件作题,不整仓啃;没读过才能当题——先归档不预览
2. **AI 生成变体**:基于刚学完的原理出"换场景不换原理"的变体题,带难度标签(①-⑤)
3. **.Prime 存量**:自己 AI 敲的旧代码,天然是"写过但没消化"的题

**素材源索引 `sources/index.md`(防过拟合):**
| 仓库/来源 | 文件 | 方向 | 是否已用 | 用后命中率 |

## 六、升级判定(双轨制)

- 删掉"闭卷重写 + 数值误差 <1e-5"(原标准)
- 判断轨命中率按负重级分段统计:**每一级内,连续 2 轮命中率 ≥80% → 升一级**
- 命中率只统计新场景预测
- 学习轨不直接升级,但**学习轨连续 2 次被追问卡住同一原理 → 禁止升级**

**难度策略:** 判断轨**先固定在①级**,连续 2 轮命中率 ≥80% 后再提升难度;学习轨难度不设限(只求理解)。

**升一级后:** 判断轨题目难度上调(混合比例中 A 盲猜增加);学习轨物体从 level1 → level2。

## 八、模板定义

### 判断轨账本 `ledgers/_template.md`

```markdown
# 判断轨记录 #N — <陌生物体>
日期: | 负重级: | 来源:(GitHub/AI变体/.Prime) | 是否新场景:是

## 题目
(这个函数/文件做什么的——只贴签名/注释,不贴实现)

## 预测(3-5条,每条必含:预测内容 + 通过判据)
| # | 预测 | 判据 | 结果 |
|---|------|------|------|
| 1 | <具体到可证伪> | <数值/形状/行为> | 对/错 |

## 验证
(跑的 toolkit/实验,贴关键结果)

## 偏差记录(最值钱)
(哪条预测错了,为什么错——内部模型哪里和现实不符)

## 修复(内部模型更新)
(下次同类预测该怎么做)
```

```
3句话讲清核心 | 300-500字展开 | 1-2个自创例子 | 一句"没有X会怎样"
```

- **新增铁律**:见过的题不算数;AI 生成变体必须"换场景不换原理"
