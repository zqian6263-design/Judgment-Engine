# 循环记录 #001 — 认领：线性回归的梯度下降（.Prime/Phase0/LinearRegression.py）

日期：2026-07-31
负重级：② 动态

## 1. 物体
.Prime/Phase0/LinearRegression.py —— AI 敲的、没消化的代码。用完整循环把它认领。

## 2. 建立内部模型（解释关）
逐行讲清楚关键部分：
- `y = 2*x + 1 + 0.1*np.random.randn(100, 1)`：真实关系 y=2x+1，加噪声模拟现实，100 个样本
- `loss_w(w_val) = np.mean((y - (w_val*x + b))**2)`：MSE 损失；把 w 抽成函数参数，才能对 w 做数值梯度
- `w -= lr * dw`：梯度下降更新；dw = dL/dw，lr 是步长

## 3. 预测
| # | 预测 | 结果 |
|---|------|------|
| 1 | 若 lr=10，loss 会先震荡再发散成 NaN | 对 |
| 2 | 若 lr=1e-8，loss 几乎不动 | 对 |
| 3 | 收敛后 w 应接近 2.0、b 接近 1.0 | 对 |

## 4. 验证
- 数值梯度 vs 手写梯度 dL/dw = mean(-2x(y-pred))：相对误差 3e-7 ✅
- 分别跑 lr=10 / 1e-8 / 0.1 三组，对比 loss 曲线
- 收敛后 w≈2.001、b≈1.002 ✅

## 5. 偏差记录
- 我以为"lr 大就立刻发散"，实际 lr=10 是先震荡几个 epoch 再发散——发散前有震荡期
- 我之前没意识到 `np.mean()` 里的 1/n 会随样本数影响实际步长

## 6. 修复（内部模型更新）
- 学习率的"危险区间"是一个范围，不是单点；发散前往往先震荡
- 有效步长 ≈ lr / n（batch 大小通过均值影响实际学习率）；预测 lr 行为时先想有效步长
